# WzrdTerm releases

Signed and notarized WzrdTerm builds for macOS 26 (Tahoe) and later.
WzrdTerm is a project-based terminal emulator.

## Install with Homebrew

```bash
brew install --cask brndnsvr/tap/wzrdterm
```

Update with:

```bash
brew update && brew upgrade --cask wzrdterm
```

Or download the DMG from [Releases](https://github.com/brndnsvr/WzrdTerm-releases/releases).
